# Библия Aion 2

Неофициальный русский справочник по Aion 2 для PvE: экипировка, перенос, навыки, арканы, даэванион, питомцы, крылья, урон.

**Открыть:** https://lanqvist.github.io/aion2-bible/

Русская переработка англоязычного гайда **Kanon** (снимок от 4 октября 2026). Автор исходного текста и иллюстраций — Kanon:
https://docs.google.com/document/d/11u4wLCG1WfL-xSka2Aze0rI9vYRa7mq3N3Gp1bt0AWY/edit?tab=t.0

«Global по гайду» — пометка автора, а не независимая проверка в клиенте. KR/Азия и неподтверждённые механики отделены в тексте. Шесть иллюстраций переведены как справка и не являются скриншотами локализованного клиента.

Статический сайт без зависимостей: `index.html`, `app.css`, `app.js`, `data.js`, `images/`, `translations/`. Избранное, тема и место чтения хранятся в `localStorage` браузера.
